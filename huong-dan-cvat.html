Lab Ngày 5 — Hướng dẫn chi tiết (Terminal + CVAT)

Mỗi bước bên dưới có lệnh PowerShell và ảnh chụp toàn màn hình / toàn trang thật trên máy. Làm theo thứ tự từ trên xuống.

1. Terminal setup 2. Tải ảnh 3. Docker CVAT 4. Mở CVAT 5. Settings 6. Vẽ Track 7. Export + check

Terminal Bước 1 — Vào repo, tạo venv, cài thư viện

Mở PowerShell (Win + R → powershell → Enter), phóng to cửa sổ, gõ lần lượt:

# 1) Vào thư mục repo cd C:\Users\phamv\Downloads\K5-L2-MOTTracking # 2) Tạo môi trường ảo Python py -3 -m venv .venv # 3) Cài cvat-sdk + Pillow (file requirements-local.txt) .\.venv\Scripts\python.exe -m pip install -r src/requirements-local.txt

Terminal Bước 2 — Nhận đề theo MSSV + tải 150 ảnh

Đổi DEMO2024 thành MSSV thật của bạn.

# Chỉ xem mã đề (A/B/C) — không cần mật khẩu CVAT .\.venv\Scripts\python.exe src/setup_local_lab.py --mssv DEMO2024 --assignment-only # Tải 150 ảnh MOT17-09 + tạo bảng nhận diện P1–P5 .\.venv\Scripts\python.exe src/setup_local_lab.py --mssv DEMO2024 --prepare-only # Kiểm tra đã đủ 150 ảnh (Get-ChildItem .lab-local\mot17-09\*.jpg).Count
Khi sẵn sàng tạo task trên CVAT, chạy không có --prepare-only (sẽ hỏi username + mật khẩu CVAT local):
.\.venv\Scripts\python.exe src/setup_local_lab.py --mssv MSSV_CUA_BAN
Script in ra link Task và Job.

Terminal Bước 3 — Kiểm tra Docker CVAT đang chạy

docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
Mở trình duyệt: http://localhost:8080 → thấy trang Sign in / Tasks là OK.

CVAT Bước 4 — Đăng nhập, tìm task, mở job

  1. Vào http://localhost:8080, đăng nhập tài khoản CVAT trên máy bạn.
  2. Tab Tasks → search đúng tên task script đã in (ví dụ DAY05-MOT17-09-B-DEMO2024).
  3. Mở task → kiểm tra nhãn person, Job có Frame range 0–149 (150 frame).
  4. Bấm Job để vào workspace annotation.

CVAT Bước 5 — CP0: Settings Player + Workspace

Trong job, bấm F2 (hoặc menu user → Settings).

  1. Player: đặt Player step = 10 → phím V/C nhảy 10 frame.
  2. Workspace: bật Enable auto save, bật Always show object details.
  3. Xem hết 150 frame một lượt; mở bảng nhận diện, ghi chỗ rẽ / che của P1–P5.

Phím dùng liên tục

Không dùng Propagate (Ctrl+B) — tạo shape rời, không có track ID chung.

CVAT Bước 6 — CP1: Vẽ Rectangle Track

  1. Về frame xuất hiện đầu của người (theo bảng nhận diện).
  2. Thanh trái → Rectangle.
  3. Popup: Label = person → chọn Track (không chọn Shape) → Drawing method = By 2 points.
  4. Vẽ sát toàn thân; đặt tên object P1…P5.
  5. Nhảy V; box lệch thì kéo (tự thành keyframe). Tua F giữa 2 keyframe để sửa drift.
  6. Ctrl+S sau mỗi người. Panel Objects phải có đúng 5 dòng dạng RECTANGLE TRACK.

CP2 nhanh — đoạn bị che (P1)

  • Che một phần: Q (occluded), box vẫn bao toàn thân ước lượng.
  • Mất hẳn: O (outside).
  • Hiện lại ≤ 60 frame: tắt outside, giữ cùng ID. Lỡ 2 track → Merge M.

CVAT + Terminal Bước 7 — Export + tự kiểm

7a. Export trên CVAT (2 lần)

  1. Job → Menu → Export job dataset.
  2. Lần 1: format MOT 1.1, Save images = OFF, tên HoVaTen_mot.zip.
  3. Lần 2: format CVAT for video 1.1, Save images OFF, tên HoVaTen_cvat_video.zip.
  4. Đặt cả hai vào src/exports/.

7b. Chạy script tự kiểm trong Terminal

.\.venv\Scripts\python.exe src/check_submission.py ` --mot src/exports/HoVaTen_mot.zip ` --cvat src/exports/HoVaTen_cvat_video.zip
Xong CP4: 2 file trong src/exports/, báo cáo report/individual/MSSV_HoTen.md đủ mục, job → completed.
